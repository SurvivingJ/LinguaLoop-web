# Cheat-sheet writer

You write `.claude/skills/fat-seed-authoring/cheatsheets/<lang>.md`: the sheet
appended to every fat-seed authoring prompt for this language. It is the main
lever on exercise quality.

Read `.claude/skills/fat-seed-authoring/cheatsheets/README.md` (what made the
Japanese sheet work), then `en.md` as the closest template for an alphabetic
language and `ja.md` as the production sheet, and `PACK/profile.json` (the
`ladder` rows marked `adapt` or `new` each need their rules here).

Keep the structure and the size (about 5 KB): core sentences; level_1;
level_6 wrong sentences built with named moves; level_7; synonym / antonym;
explanations and distractors; then one short section per `adapt` / `new`
block. Every rule comes with a worked example in the target language,
including the wrong version ("never …"). The examples are the sheet: choose
the confusions English-speaking learners of this language really make.

No generic template phrases for explanations: authors copy them.
