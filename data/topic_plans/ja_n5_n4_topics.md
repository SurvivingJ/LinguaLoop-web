# Japanese N5/N4 Topic Plan — 100 tests

Planned 2026-11-08 for generation by an Opus author. Target tiers: **N5 ≈ T1**, **N4 ≈ T2**
(see `wiki/features/test-tier-assignment.md`).

## What we have today (ja, as of 2026-11-08)

| Tier | Tests | Notes |
|------|-------|-------|
| T1 (difficulty 1) | 5 active (+1 inactive counter drill) | 50–65 chars each — about three sentences |
| T2 (difficulty 3) | 6 | 50–65 chars |
| T3 (difficulty 5) | 7 | ~170 chars |
| T4 (difficulty 6) | 15 | |
| T5–T6 (difficulty 7–9) | 26 | Abstract or academic topics |

Gaps this plan fills:

1. **Almost no beginner content.** Only 11 tests are at T1–T2, the level of an N5/N4 learner.
2. **The topics don't fit beginners.** The shared topic pool is written for every language and
   built around adult concepts. Several T1–T2 tests squeeze ideas like pharmacogenomics,
   post-Westphalian sovereignty, Roman aqueducts and an AI-agent product into a child's
   register. None covers the everyday situations that N5/N4 study is built on: shopping,
   transport, the clinic, rubbish sorting, invitations.
3. **Every test uses one style.** All Japanese tests are `style = academic`, so there are no
   dialogues, diaries, notices or emails. N4 listening relies heavily on dialogues.
4. **The passages are too short.** At three sentences they give the questions little to work
   with. Suggested lengths: **N5 80–150 characters, N4 150–300 characters**.

## How the plan is built

- **40 N5 and 60 N4 topics** in 14 everyday themes, following the JLPT N5/N4 can-do situations.
- **Each topic has a format**: narrative, diary, dialogue, notice or email/letter.
- **Each topic has a grammar focus.** The focus points are spread out so that the 100 tests
  cover the N5/N4 grammar syllabus (て-form, ている, たい, たり, てしまう, ておく, てみる,
  あげる/もらう/くれる, potential, passive, ば/たら/と, そう, よう, つもり, ほうがいい,
  なければならない, てもいい/てはいけない, comparison, と思う/と言っていた, volitional).
- **Kanji:** N5 tests use N5 kanji only, with hiragana for everything else. N4 tests use
  N5+N4 kanji. Furigana is handled by the existing payload pipeline.
