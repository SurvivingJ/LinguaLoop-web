L1（聞き取り — リスニング練習）：
- 場面：学習者は対象語の「音声」（合成音声が一度だけ読み上げる）を聞き、4 つの書記選択肢から正しい表記を選ぶ。
- 対象学習者：{tier_display}（{tier_age_range}）。

**この JSON 出力には、レベル "1" 〜 "6" のキーに加えて、"l1_grid" という追加のトップレベルキーを必ず含めること。これは採点対象ではなく、あなた自身の検証記録である。**

"l1_grid" の作り方（この順で、省略せずに行うこと）：
1. 対象語の読みをモーラに分割し、配列で書く（例："むかし" → ["む","か","し"]）。
2. 各モーラ位置について、他の主要なモーラ（少なくとも 8 個）に置き換えた場合の読みを機械的に生成する。
3. 生成した読み一つ一つについて、次の形のオブジェクトを作る：
   {"position": 位置番号, "original_mora": 元のモーラ, "substituted_mora": 置換後のモーラ, "candidate_reading": 生成された読み, "is_real_word": true/false, "surface_form": 実在する場合の通常の表記（実在しなければ空文字）, "meaning": 実在する場合の意味を一言で（実在しなければ空文字）}
4. "is_real_word" を true にできるのは、その語を国語辞典の見出し語として言え、読みと意味を淀みなく言える場合だけである。判断に迷う場合は false とする。
5. "l1_grid" はこれらのオブジェクトを全て含む配列とする。省略や間引きをしてはならない — 試した組み合わせは全て記録に残す。

レベル "1" の生成規則：
- 正解 1 個 = 対象語。
- ディストラクターは、"l1_grid" の中で "is_real_word": true になった候補の "surface_form" からのみ選ぶこと。"l1_grid" に存在しない語をディストラクターに使ってはならない — これは自己矛盾であり、出力全体が拒否される。
- "l1_grid" で true になった候補が 3 個以上あれば、そこから関門 4（使ってはならないもの）に該当しないものを 3〜5 個選ぶ。
- true になった候補が 3 個未満の場合は、それをそのまま使う。個数を埋めるために "l1_grid" にない語を追加してはならない。
- 関門 2（表記）：正解・ディストラクターとも、その語を普通に書くときの表記を使う。対象語の字種（漢字／かな）に揃えるために表記を作り替えてはならない。
- 関門 4（使ってはならないもの）：
  - 対象語の同義語・類義語（音を聞いた学習者が正解として選びうるため）。
  - 対象語と読みもアクセントも同じ同音異義語（「機械」に対する「機会」、「箸」に対する「橋」は不可 — ただし "l1_grid" はモーラ置換で生成するため、読みが完全に同じ語はそもそも候補に現れないはずである。現れた場合は関門違反として除外する）。
  - 高低アクセントだけが異なる語も、同じ理由で不可。
  - 表記だけが似て読みが異なる語（聴覚で区別できてしまう形近語）。
  - 対象語そのもの、および対象語の活用形。
  - {tier_display} の語彙帯を明らかに超える古語・専門語・稀少語（"l1_grid" 上は実在でも、レベルに合わないものは選ばない）。
- 解説："2"=false の各項について、"l1_grid" に記録した意味と、対象語との差（一モーラ差・清濁・長音・促音の別）を述べる。

出力スキーマの注記：トップレベルキーは "l1_grid" と、生成対象のレベル番号（"1"、"3" など）である。"l1_grid" はレベル番号ではないため既存のパーサーはこのキーを無視する — レベル "1" の配列だけが選択肢として使われる。レベル "1" の配列は 4〜6 個の選択肢オブジェクトとする。
