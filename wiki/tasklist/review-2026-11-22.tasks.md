## TASK-1200: Smoke-test `record_exercise_attempt` on the live database before deploying

**Status:** [ ] Not Started
**Feature:** codebase-review-2026-11-22
**Type:** infra
**Complexity:** S (1-3h)
**Depends On:** none

**Description:**
`record_exercise_attempt` is now the only practice-attempt path (the code flag `PRACTICE_ATTEMPT_RPC_ENABLED` is ignored and the old multi-call path is deleted). It has never been called in production and no test executes its SQL. Before the code is deployed the owner runs it once inside `BEGIN; ... ROLLBACK;` against the live project and checks the result shape. Owner action; this blocks the deploy (TASK-1233).

**Acceptance Criteria:**
- [ ] A call with a real user id, an exercise id with a card, `is_correct = true` and a call with `is_correct = false` both return without error inside a transaction that is rolled back
- [ ] The returned JSON has the keys the Python caller in `services/practice/attempt_recording.py` reads (check the caller before the call, list the keys in the task result)
- [ ] After ROLLBACK, `SELECT count(*)` on `exercise_attempts` and `user_flashcards` for that user is unchanged
- [ ] A first attempt on a sense with no card, and a call with a NULL exercise type, are also run (the 4-argument overload drop in TASK-1201 item 1 does not depend on this, but the NULL-type case documents the behaviour)

**Technical Notes:**
Definition: `migrations/record_exercise_attempt.sql` (the repo copy is byte-identical to live apart from comments). It calls `update_vocabulary_from_word_test` with 5 arguments. Expected cost after the change: 2 database calls for a first attempt with a card, 1 otherwise ([[features/practice-package.tech]]). Use the Supabase SQL editor or the MCP `execute_sql`; wrap in `BEGIN; SELECT record_exercise_attempt(...); ROLLBACK;` in a single statement batch so nothing commits. Do not run it with a user id that is a real learner unless the transaction is rolled back in the same batch.

**Files to Create / Modify:**

- `services/practice/attempt_recording.py` — read only (argument and return shape)

**Verification:**
